# Changelog

## v0.9.174 public source distribution — 2026-10-18

- Publish the current offline modeler source with buildable About source download,
  MIT application license and retained DejaVu notices.
- Include current tool groups, transient Sketch Editor, multi-object editing,
  Mechanical tools, Chamfer chains, Mirror, Carve Out, Text/Texture, curved Split
  Plane, native/import/export workflows and Presentation shininess.
- Provide 90 self-contained public regression suites, including 19 quick suites,
  plus an explicit private-data exclusion manifest and fixture provenance.
- Provide repository ignore rules, contributor/data policies and a build/test
  GitHub Actions workflow. Runtime sources match the v0.9.174 application.

Private development history, uploaded models and raw diagnostic evidence are
not part of this public distribution. This packaging does not add a new native
file format or change application modeling behavior.
